College DBMS Demonstration Walkthrough
  1. Multi-User Isolation: Every query filters by authenticated session['user_id']; Demo Mode uses an isolated is_demo = 1 user without touching real records.
  2. ACID Transactions & Stored Procedures: Adding, editing, deleting, or CSV-importing transactions invokes sp_recalculate_holding inside an atomic transaction.
  3. Security & Resend 2FA: Argon2id password hashes, SHA-256 OTP hashes with 5-minute expiry, CSRF headers, rate limiting, CAPTCHA, and audit logging.
